# Landing Page Pawła Kwiatka

Prosty landing page prezentujący ofertę usługową Pawła Kwiatka. Zawiera sekcję bohatera, listę usług, informacje o autorze oraz sekcję kontaktową z danymi do stopki.

> Uwaga: dane kontaktowe w sekcji stopki są obecnie przykładowe i powinny zostać zaktualizowane zgodnie z rzeczywistymi informacjami.
